# Calculadora

Scaffolding inicial con React, TypeScript y Vite.

## Desarrollo

```sh
npm install
npm run dev
```

## Verificación

```sh
npm run lint
npm run build
```

Para previsualizar el build: `npm run preview`.

## Estructura

- `src/main.tsx`: punto de entrada de React.
- `src/App.tsx`: contenedor inicial de la aplicación.
- `src/index.css`: estilos básicos.
- `src/api/`: módulo de comunicación con el backend, pendiente.
- `src/components/`: componente de la calculadora, pendiente.

La integración con `POST /api/calculate`, la calculadora y los tests con Vitest
se implementarán en los siguientes pasos.
